Sr.No: 3
API Name: Upload Signed Policy Document
URL: /policies/upload-signed-document/{emp_id}/
Method: POST
Description: Upload signed document. Auto-sends email to HR with attachment.

Request Headers:
  - Authorization: Bearer <jwt_token>
  - Content-Type: multipart/form-data

Request Payload (Form Data):
  - signed_document: [File] 
    - Allowed types: PDF, JPG, JPEG, PNG, DOCX
    - Max size: 10MB

Success Response (201 Created):
{
    "message": "Signed document uploaded successfully and email sent to HR",
    "employee_id": "EMP001",
    "employee_name": "John Doe",
    "file_path": "signed_acknowledgements/EMP001_policy_acknowledgement_20260131_143025.pdf",
    "uploaded_at": "2026-01-31 14:30:25",
    "email_sent": true,
    "hr_email": "hr@thedatatechlabs.com"
}

Success Response (201 Created) - Email Failed:
{
    "message": "Document uploaded but failed to send email to HR",
    "employee_id": "EMP001",
    "employee_name": "John Doe",
    "file_path": "signed_acknowledgements/EMP001_policy_acknowledgement_20260131_143025.pdf",
    "uploaded_at": "2026-01-31 14:30:25",
    "email_sent": false,
    "email_error": "SMTP connection failed"
}

Error Responses:
  - 400: {"error": "No file uploaded. Please upload a signed document."}
  - 400: {"error": "File size exceeds maximum limit of 10.0MB"}
  - 400: {"error": "Invalid file type. Allowed types: .pdf, .jpg, .jpeg, .png, .docx"}
  - 400: {"error": "Please acknowledge all assigned policies before uploading the signed document", "acknowledged": 2, "total_policies": 5}
  - 404: {"error": "Employee not found"}
  - 500: {"error": "Failed to upload document: <error_message>"}

Sr.No: 8
API Name: Send Reminder to Employee (HR/Admin)
URL: /policies/send-reminder/{emp_id}/
Method: POST
Description: Send notification reminder to employee. Creates notification in ci_notification table.

Request Headers:
  - Authorization: Bearer <jwt_token>
  - Content-Type: application/json

Request Payload (JSON):
{
    "user_id": 123
}

Note: user_id is the logged-in HR/Admin user ID (required)

Success Response (200 OK):
{
    "message": "Reminder sent successfully to employee",
    "employee_id": "EMP002",
    "employee_name": "Jane Smith",
    "employee_email": "jane.smith@company.com",
    "reminder_sent_at": "2025-01-10 15:30:45",
    "total_reminders_sent": 3,
    "notification_sent": true
}

Error Responses:
  - 400: {"error": "user_id is required in request body"}
  - 404: {"error": "Employee not found"}
  - 400: {"error": "No policies assigned to this employee"}
  - 400: {"error": "Employee has not acknowledged all policies yet", "acknowledged": 3, "total_policies": 5}
  - 400: {"error": "Employee has already uploaded the signed document", "document_path": "signed_acknowledgements/EMP002_signed_20250110_143022.pdf", "email_status": "sent"}
  - 500: {"error": "Failed to send reminder: <error_message>"}

# USER FLOW
================================================================================

EMPLOYEE FLOW:
1. GET /policies/assigned/{emp_id}/ → Check all policies and signed_document status
2. Acknowledge all policies (existing API)
3. GET /policies/download-acknowledgement-template/{emp_id}/ → Download template
4. Sign document offline
5. POST /policies/upload-signed-document/{emp_id}/ → Upload signed document
6. GET /policies/signed-document-status/{emp_id}/ → Verify upload status

HR/ADMIN FLOW:
1. GET /policies/signed-documents-dashboard/ → View all employees status
2. POST /policies/send-reminder/{emp_id}/ → Send reminder to pending employees
3. POST /policies/resend-email/{emp_id}/ → Retry failed emails
4. GET /policies/view-signed-document/{emp_id}/ → Download employee's document

================================================================================

# email_status VALUES
================================================================================
- "not_uploaded" : Document not yet uploaded
- "pending"      : Document uploaded, email in queue (rarely used)
- "sent"         : Email successfully sent to HR
- "failed"       : Email sending failed (SMTP error)

# status VALUES (in dashboard)
================================================================================
- "Uploaded" : Document has been uploaded
- "Pending"  : Document not yet uploaded

# can_send_reminder FLAG (in enhanced dashboard)
================================================================================
- true  : Employee acknowledged all policies but hasn't uploaded → Enable Send Reminder button
- false : Either already uploaded OR hasn't acknowledged all policies → Disable button
